# Objetivo del Proyecto

Crear una aplicación de venta de bienes raíces llamada "Aura Estate", utilizando **Next.js (App Router)** y **Tailwind CSS**.

El proyecto ya está inicializado y tiene Tailwind CSS configurado, pero no cuenta con estilos personalizados ni lógica de negocio. El objetivo es implementar el diseño y las funcionalidades esenciales de una aplicación inmobiliaria premium, moderna y minimalista, guiándose rigurosamente por los recursos de diseño provistos en la carpeta [antigravity/resources/](resources/).
